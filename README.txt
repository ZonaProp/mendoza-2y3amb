ZonaProp Premium - 100 departamentos 2 y 3 ambientes en Mendoza
================================================================

Archivos:
- index.html     → grilla de tarjetas filtrable por zona y precio
- depto.html     → detalle con galería de fotos
- data.json      → 100 departamentos (53 de 2 amb. + 47 de 3 amb.)
- listado_100_mendoza.csv → listado tabular

Zonas: Ciudad de Mendoza, Primera/Quinta/Sexta Sección, Godoy Cruz,
Guaymallén, Dorrego, Luján de Cuyo, Chacras de Coria, Villa Marini,
Gobernador Benegas, Maipú, Las Heras, San José, Barraquero, etc.

Cómo usar:
1. Abrí index.html en el navegador
2. O subí a GitHub Pages / Vercel

Fotos de Bullano (mantenidas). Títulos, descripciones y direcciones adaptados a Mendoza.
